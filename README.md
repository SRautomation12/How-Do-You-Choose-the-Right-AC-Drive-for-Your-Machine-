# How-Do-You-Choose-the-Right-AC-Drive-for-Your-Machine-
Are Motors Consuming More Energy Than Expected?
A motor running at the wrong speed wastes energy, especially where the load keeps changing. Frequent starting and stopping can also affect equipment performance, depending on the process.
How Can an AC Drive Help?
An AC drive regulates motor speed to suit what the application needs. Correctly selected and configured, it gives smoother speed control and can cut unnecessary full-speed running where variable-speed control is appropriate.
What Should You Check Before Buying?
Consider motor power, voltage, current rating, load type and the speed range you need. Environmental conditions, control methods and communication requirements can also affect the choice.
